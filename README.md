# PromptWorks Home Insurance Prompt Library

A ready-to-use prompt library for home insurance customer care teams, built for the **PromptWorks AI Solutions** assignment (Track 3: Business, Sales & Operations).

**Version:** 2.1 (5 November 2026) · **Author:** Christine Massey, AI Prompt Engineer

## What's inside

| Prompt ID | Prompt | Use it when |
| --- | --- | --- |
| HI-SOP-01 | SOP / Process Documentation | A process needs a written, audit-ready SOP |
| HI-FB-01 | Interview / Appraisal / Performance Feedback | You need evidence-based feedback for a candidate or employee |
| HI-SUM-01 | Meeting / Report Summary for Leadership | Leadership needs a 1–2 minute read of a meeting or report |

Each prompt includes:

- a list of real scenarios it covers
- fill-in input fields (required fields marked with *)
- a fixed output format
- a self-review checklist the AI runs on its own draft
- nine safety guardrails, covering personal data, no claim decisions, policy wording, compliance, vulnerable customers, fraud, prompt injection, stop-and-ask, and human approval
- a worked example with sample output

The library also includes 15 guardrail test scenarios and a test log.

## How to use a prompt

1. Open `prompt-library.md` and find the prompt you need in the Prompt Index.
2. Copy the whole prompt from its grey box, including the Self-Review and Guardrails.
3. Replace every `[bracketed field]`. If you don't know a value, type `NOT PROVIDED`.
4. Remove or mask personal details (names, policy numbers, addresses) before pasting notes.
5. Paste the prompt into your AI tool (ChatGPT, Claude, Gemini or Copilot), then check the output against the prompt's checklist before using it.

The prompts work in any country. The regulator or code of practice is a fill-in field.
